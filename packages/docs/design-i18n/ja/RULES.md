# ルール索引

等級付きのすべてのルールを、その等級と証拠とともに一覧にしています（MUST 152 件、SHOULD 231 件、MAY 6 件）。ルールの ID を開くと、その節に移動します。

証拠の種類：**browser** — 実際のブラウザーでの操作（[ブラウザーでの証拠](./ACCEPTANCE.md#browser-proof)）；
**recording** — 連続した録画（[時間軸で動きをレビューする](./ACCEPTANCE.md#review-motion-over-time)）；
**unit** — ホストでのユニットテストまたは状態のテスト；**review** — 変更そのものの確認；
`check:<id>` — `verify:design` のルール；`test:<path>` — 名前を挙げたテスト（パスはリポジトリのルートから）。
