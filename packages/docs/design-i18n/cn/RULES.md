# 规则索引

所有分级规则，附等级和验证方式（152 条 MUST、231 条 SHOULD、6 条 MAY）。点击规则 ID 可跳到所在章节。

验证方式：**browser**：真实浏览器交互（[浏览器证据](./ACCEPTANCE.md#browser-proof)）；
**recording**：连续录屏（[时间维度的动效](./ACCEPTANCE.md#review-motion-over-time)）；
**unit**：宿主中的单元或状态测试；**review**：检查改动本身；
`check:<id>`：一条 `verify:design` 规则；`test:<path>`：指定的测试（路径从仓库根目录算起）。
