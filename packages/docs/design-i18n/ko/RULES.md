# 규칙 색인

등급이 붙은 모든 규칙과 그 등급, 증거 방식을 모았습니다(MUST 152개, SHOULD 231개, MAY 6개). 규칙 ID를 열면 해당 절로 이동합니다.

증거 종류: **browser** — 실제 브라우저 상호작용([브라우저 증거](./ACCEPTANCE.md#browser-proof));
**recording** — 연속 녹화([시간에 따른 모션 검토](./ACCEPTANCE.md#review-motion-over-time));
**unit** — 호스트의 단위 테스트나 상태 테스트; **review** — 변경 자체에 대한 점검;
`check:<id>` — `verify:design` 규칙; `test:<path>` — 이름이 지정된 테스트(경로는 저장소 루트 기준).
