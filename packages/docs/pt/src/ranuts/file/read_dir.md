# ReadDir

Lê todos os arquivos de um diretório.

## API

### Retorna

- Promise

| Parâmetro | Descrição                                | Tipo    | Descrição                    |
| --------- | ---------------------------------------- | ------- | ---------------------------- |
| result    | Array com todos os arquivos do diretório | `array` | Array de caminhos de arquivo |

### Opções

| Parâmetro | Descrição            | Tipo     | Padrão      |
| --------- | -------------------- | -------- | ----------- |
| options   | { dirPath }          | `object` | Obrigatório |
| dirPath   | Caminho do diretório | `string` | Obrigatório |
