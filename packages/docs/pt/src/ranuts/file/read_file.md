# ReadFile

Lê o conteúdo de um arquivo.

## API

### Retorna

- Promise

| Parâmetro | Descrição           | Tipo     | Descrição                         |
| --------- | ------------------- | -------- | --------------------------------- |
| data      | Conteúdo do arquivo | `string` | O conteúdo do arquivo como string |

### Opções

| Parâmetro | Descrição                | Tipo     | Padrão    |
| --------- | ------------------------ | -------- | --------- |
| path      | Caminho do arquivo a ler | `string` | undefined |
