# Ran Design

Um guia de design para construir interfaces de produto, independente de qualquer biblioteca de componentes.

Segue a ordem em que se projeta: comece pela tarefa e pelo conteúdo real, defina uma única linguagem visual, organize e componha a página, projete a interação e o movimento e verifique a mudança em um navegador real. Termina com listas de verificação para cada mudança.
