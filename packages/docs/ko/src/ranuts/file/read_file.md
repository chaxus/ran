# ReadFile

파일 내용을 읽습니다.

## API

### 반환값

- Promise

| 매개변수 | 설명      | 타입     | 설명                  |
| -------- | --------- | -------- | --------------------- |
| data     | 파일 내용 | `string` | 문자열로 된 파일 내용 |

### 옵션

| 매개변수 | 설명           | 타입     | 기본값    |
| -------- | -------------- | -------- | --------- |
| path     | 읽을 파일 경로 | `string` | undefined |
