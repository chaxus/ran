# WatchFile

파일이 바뀌었는지 지켜봅니다.

## API

### 반환값

- Promise

| 매개변수 | 설명                   | 타입      | 설명                          |
| -------- | ---------------------- | --------- | ----------------------------- |
| status   | 파일이 바뀌었는지 여부 | `boolean` | 바뀌었으면 true, 아니면 false |

### 옵션

| 매개변수 | 설명                              | 타입     | 기본값    |
| -------- | --------------------------------- | -------- | --------- |
| path     | 지켜볼 파일 경로                  | `string` | undefined |
| interval | 파일 변화를 지켜보는 간격(밀리초) | `number` | `20`      |
