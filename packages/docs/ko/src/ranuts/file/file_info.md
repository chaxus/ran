# QueryFileInfo

파일의 자세한 정보를 조회합니다. 파일과 디렉터리를 가려내는 데 흔히 쓰이며, 돌려받은 데이터(`data.isDirectory()`)로 판별할 수 있습니다.

## API

### 반환값

- Promise

| 매개변수 | 설명                        | 타입      | 설명                        |
| -------- | --------------------------- | --------- | --------------------------- |
| success  | 확인에 성공했는지 여부      | `boolean` | 성공이면 true, 실패면 false |
| data     | 파일 정보, 또는 오류의 이유 | `Stats`   |                             |

### 옵션

| 매개변수 | 설명             | 타입     | 기본값    |
| -------- | ---------------- | -------- | --------- |
| path     | 확인할 파일 경로 | `string` | undefined |
