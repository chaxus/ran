# AppendFile

파일에 데이터를 덧붙입니다.

## API

### 반환값

- Promise

| 매개변수 | 설명                                                 | 타입      | 설명                        |
| -------- | ---------------------------------------------------- | --------- | --------------------------- |
| success  | 덧붙이기에 성공했는지 여부                           | `boolean` | 성공이면 true, 실패면 false |
| data     | 덧붙이기에 실패한 이유, 또는 성공했을 때의 파일 내용 | `any`     |                             |

### 옵션

| 매개변수 | 설명             | 타입     | 기본값    |
| -------- | ---------------- | -------- | --------- |
| path     | 덧붙일 파일 경로 | `string` | undefined |
| content  | 덧붙일 내용      | `string` | 필수      |
