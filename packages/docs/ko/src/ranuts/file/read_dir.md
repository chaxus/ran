# ReadDir

디렉터리 안의 모든 파일을 읽습니다.

## API

### 반환값

- Promise

| 매개변수 | 설명                         | 타입    | 설명             |
| -------- | ---------------------------- | ------- | ---------------- |
| result   | 디렉터리 안 모든 파일의 배열 | `array` | 파일 경로의 배열 |

### 옵션

| 매개변수 | 설명          | 타입     | 기본값 |
| -------- | ------------- | -------- | ------ |
| options  | { dirPath }   | `object` | 필수   |
| dirPath  | 디렉터리 경로 | `string` | 필수   |
