# Ran Design

특정 컴포넌트 라이브러리에 의존하지 않는, 제품 인터페이스를 위한 디자인 가이드입니다.

디자인하는 순서를 따릅니다. 작업과 실제 콘텐츠에서 출발해 하나의 시각 언어를 정하고, 페이지를 배치하고 구성한 뒤, 상호작용과 모션을 설계하고, 실제 브라우저에서 변경을 확인합니다. 마지막의 체크리스트는 변경할 때마다 다시 쓸 수 있습니다.
