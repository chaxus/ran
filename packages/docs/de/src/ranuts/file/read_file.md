# ReadFile

Liest den Inhalt einer Datei.

## API

### Rückgabe

- Promise

| Parameter | Beschreibung    | Typ      | Beschreibung                     |
| --------- | --------------- | -------- | -------------------------------- |
| data      | Der Dateiinhalt | `string` | Der Dateiinhalt als Zeichenkette |

### Optionen

| Parameter | Beschreibung               | Typ      | Standard  |
| --------- | -------------------------- | -------- | --------- |
| path      | Pfad der zu lesenden Datei | `string` | undefined |
