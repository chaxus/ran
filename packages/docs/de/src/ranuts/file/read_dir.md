# ReadDir

Liest alle Dateien in einem Verzeichnis.

## API

### Rückgabe

- Promise

| Parameter | Beschreibung                       | Typ     | Beschreibung          |
| --------- | ---------------------------------- | ------- | --------------------- |
| result    | Array aller Dateien im Verzeichnis | `array` | Array von Dateipfaden |

### Optionen

| Parameter | Beschreibung            | Typ      | Standard     |
| --------- | ----------------------- | -------- | ------------ |
| options   | { dirPath }             | `object` | Erforderlich |
| dirPath   | Pfad des Verzeichnisses | `string` | Erforderlich |
