# Ran Design

Eine einseitige Design-Checkliste für Produktoberflächen, unabhängig von einer Komponentenbibliothek.

Vor dem Start, beim Bauen und vor der Übergabe einer Änderung. Sie enthält Steve Krugs Fünf-Sekunden- und Kofferraum-Test und markiert, was ein Browsertest automatisch prüft.
