# ReadDir

读取一个目录下的所有文件。

## API

### Return

- Promise

| 参数   | 说明                 | 类型    | 描述         |
| ------ | -------------------- | ------- | ------------ |
| result | 目录下所有文件的数组 | `array` | 文件路径数组 |

### Options

| 参数    | 说明        | 类型     | 默认值 |
| ------- | ----------- | -------- | ------ |
| options | { dirPath } | `object` | 必填   |
| dirPath | 目录路径    | `string` | 必填   |
