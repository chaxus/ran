# ReadFile

读取文件内容。

## API

### Return

- Promise

| 参数 | 说明     | 类型     | 描述                       |
| ---- | -------- | -------- | -------------------------- |
| data | 文件内容 | `string` | 以字符串形式返回的文件内容 |

### Options

| 参数 | 说明             | 类型     | 默认值    |
| ---- | ---------------- | -------- | --------- |
| path | 要读取的文件路径 | `string` | undefined |
