# WriteFile

将内容写入文件。

## API

### Return

- Promise

| 参数    | 说明                                             | 类型      | 描述                 |
| ------- | ------------------------------------------------ | --------- | -------------------- |
| success | 是否写入成功                                     | `boolean` | true 成功 false 失败 |
| data    | 写入失败时是失败原因，成功时是文件内容和文件路径 | `any`     |                      |

### Options

| 参数    | 说明             | 类型     | 默认值    |
| ------- | ---------------- | -------- | --------- |
| path    | 要写入的文件路径 | `string` | undefined |
| content | 要写入的内容     | `string` | 必填      |
