# Ran Design

一份构建产品界面的设计指南，不依赖特定组件库。

它按设计的顺序展开：从任务和真实内容出发，确定统一的视觉语言，排布和组合页面，设计交互与动效，最后在真实浏览器里验证改动。结尾的检查清单可以在每次改动时复用。
