# ReadDir

Lee todos los archivos de un directorio.

## API

### Devuelve

- Promise

| Parámetro | Descripción                                 | Tipo    | Descripción               |
| --------- | ------------------------------------------- | ------- | ------------------------- |
| result    | Array con todos los archivos del directorio | `array` | Array de rutas de archivo |

### Opciones

| Parámetro | Descripción         | Tipo     | Por defecto |
| --------- | ------------------- | -------- | ----------- |
| options   | { dirPath }         | `object` | Obligatorio |
| dirPath   | Ruta del directorio | `string` | Obligatorio |
