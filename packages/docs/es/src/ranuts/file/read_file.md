# ReadFile

Lee el contenido de un archivo.

## API

### Devuelve

- Promise

| Parámetro | Descripción           | Tipo     | Descripción                          |
| --------- | --------------------- | -------- | ------------------------------------ |
| data      | Contenido del archivo | `string` | El contenido del archivo como cadena |

### Opciones

| Parámetro | Descripción             | Tipo     | Por defecto |
| --------- | ----------------------- | -------- | ----------- |
| path      | Ruta del archivo a leer | `string` | undefined   |
