# Ran Design

コンポーネントライブラリに依存しない、プロダクト UI のためのデザインガイド。

設計する順に並んでいます。タスクと実際の内容から始め、視覚言語を一つに決め、ページを配置・構成し、操作とモーションを設計し、最後に実際のブラウザーで変更を確かめます。最後のチェックリストは変更のたびに使えます。
