# WatchFile

ファイルが変更されたかどうかを監視します。

## API

### 戻り値

- Promise

| パラメーター | 説明                         | 型        | 説明                                  |
| ------------ | ---------------------------- | --------- | ------------------------------------- |
| status       | ファイルが変更されたかどうか | `boolean` | 変更されていれば true、なければ false |

### オプション

| パラメーター | 説明                                   | 型       | 既定値    |
| ------------ | -------------------------------------- | -------- | --------- |
| path         | 監視するファイルパス                   | `string` | undefined |
| interval     | ファイルの変更を監視する間隔（ミリ秒） | `number` | `20`      |
