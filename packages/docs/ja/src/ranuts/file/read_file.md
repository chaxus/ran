# ReadFile

ファイルの内容を読み取ります。

## API

### 戻り値

- Promise

| パラメーター | 説明           | 型       | 説明                         |
| ------------ | -------------- | -------- | ---------------------------- |
| data         | ファイルの内容 | `string` | 文字列としてのファイルの内容 |

### オプション

| パラメーター | 説明                 | 型       | 既定値    |
| ------------ | -------------------- | -------- | --------- |
| path         | 読み取るファイルパス | `string` | undefined |
