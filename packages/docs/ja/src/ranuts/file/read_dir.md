# ReadDir

ディレクトリ内のすべてのファイルを読み取ります。

## API

### 戻り値

- Promise

| パラメーター | 説明                                   | 型      | 説明               |
| ------------ | -------------------------------------- | ------- | ------------------ |
| result       | ディレクトリ内のすべてのファイルの配列 | `array` | ファイルパスの配列 |

### オプション

| パラメーター | 説明               | 型       | 既定値 |
| ------------ | ------------------ | -------- | ------ |
| options      | { dirPath }        | `object` | 必須   |
| dirPath      | ディレクトリのパス | `string` | 必須   |
