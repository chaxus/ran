# AppendFile

ファイルにデータを追記します。

## API

### 戻り値

- Promise

| パラメーター | 説明                                                     | 型        | 説明                          |
| ------------ | -------------------------------------------------------- | --------- | ----------------------------- |
| success      | 追記に成功したかどうか                                   | `boolean` | 成功なら true、失敗なら false |
| data         | 追記に失敗した理由、あるいは成功したときのファイルの内容 | `any`     |                               |

### オプション

| パラメーター | 説明                 | 型       | 既定値    |
| ------------ | -------------------- | -------- | --------- |
| path         | 追記先のファイルパス | `string` | undefined |
| content      | 追記する内容         | `string` | 必須      |
