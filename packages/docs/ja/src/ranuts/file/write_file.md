# WriteFile

ファイルに内容を書き込みます。

## API

### 戻り値

- Promise

| パラメーター | 説明                                                               | 型        | 説明                          |
| ------------ | ------------------------------------------------------------------ | --------- | ----------------------------- |
| success      | 書き込みに成功したかどうか                                         | `boolean` | 成功なら true、失敗なら false |
| data         | 書き込みに失敗した理由、あるいは成功したときのファイルの内容とパス | `any`     |                               |

### オプション

| パラメーター | 説明                     | 型       | 既定値    |
| ------------ | ------------------------ | -------- | --------- |
| path         | 書き込み先のファイルパス | `string` | undefined |
| content      | 書き込む内容             | `string` | 必須      |
