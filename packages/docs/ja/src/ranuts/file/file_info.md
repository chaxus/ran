# QueryFileInfo

ファイルの詳しい情報を問い合わせます。ファイルとディレクトリを見分けるのによく使われ、返ってきたデータ（`data.isDirectory()`）から判別できます。

## API

### 戻り値

- Promise

| パラメーター | 説明                                 | 型        | 説明                          |
| ------------ | ------------------------------------ | --------- | ----------------------------- |
| success      | 確認に成功したかどうか               | `boolean` | 成功なら true、失敗なら false |
| data         | ファイルの情報、あるいはエラーの理由 | `Stats`   |                               |

### オプション

| パラメーター | 説明                 | 型       | 既定値    |
| ------------ | -------------------- | -------- | --------- |
| path         | 確認するファイルパス | `string` | undefined |
