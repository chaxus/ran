# WatchFile

می‌پاید که آیا فایلی تغییر کرده است.

## API

### بازگشت

- Promise

| پارامتر | توضیح                       | نوع       | توضیح                            |
| ------- | --------------------------- | --------- | -------------------------------- |
| status  | اینکه فایل تغییر کرده یا نه | `boolean` | اگر تغییر کرده true، وگرنه false |

### گزینه‌ها

| پارامتر  | توضیح                                        | نوع      | پیش‌فرض   |
| -------- | -------------------------------------------- | -------- | --------- |
| path     | مسیر فایلی که پاییده می‌شود                  | `string` | undefined |
| interval | بازه پاییدن تغییرهای فایل، بر حسب میلی‌ثانیه | `number` | `20`      |
