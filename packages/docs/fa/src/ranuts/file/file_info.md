# QueryFileInfo

اطلاعات تفصیلی یک فایل را می‌پرسد. بیشتر برای تشخیص فایل از پوشه به کار می‌رود، که از داده بازگشتی (`data.isDirectory()`) معلوم می‌شود.

## API

### بازگشت

- Promise

| پارامتر | توضیح                       | نوع       | توضیح                         |
| ------- | --------------------------- | --------- | ----------------------------- |
| success | اینکه بررسی موفق بوده یا نه | `boolean` | در موفقیت true، در شکست false |
| data    | اطلاعات فایل، یا دلیل خطا   | `Stats`   |                               |

### گزینه‌ها

| پارامتر | توضیح                      | نوع      | پیش‌فرض   |
| ------- | -------------------------- | -------- | --------- |
| path    | مسیر فایلی که بررسی می‌شود | `string` | undefined |
