# AppendFile

داده را به انتهای یک فایل می‌افزاید.

## API

### بازگشت

- Promise

| پارامتر | توضیح                                           | نوع       | توضیح                         |
| ------- | ----------------------------------------------- | --------- | ----------------------------- |
| success | اینکه افزودن موفق بوده یا نه                    | `boolean` | در موفقیت true، در شکست false |
| data    | دلیل شکست افزودن، یا در صورت موفقیت محتوای فایل | `any`     |                               |

### گزینه‌ها

| پارامتر | توضیح                             | نوع      | پیش‌فرض   |
| ------- | --------------------------------- | -------- | --------- |
| path    | مسیر فایلی که به آن افزوده می‌شود | `string` | undefined |
| content | محتوایی که افزوده می‌شود          | `string` | الزامی    |
