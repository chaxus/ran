# ReadFile

## API

### بازگشت

- Promise

| پارامتر | توضیح       | نوع      | توضیح                    |
| ------- | ----------- | -------- | ------------------------ |
| data    | محتوای فایل | `string` | محتوای فایل به‌صورت رشته |

### گزینه‌ها

| پارامتر | توضیح                       | نوع      | پیش‌فرض   |
| ------- | --------------------------- | -------- | --------- |
| path    | مسیر فایلی که خوانده می‌شود | `string` | undefined |
