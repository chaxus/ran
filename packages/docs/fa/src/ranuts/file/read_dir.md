# ReadDir

همه فایل‌های یک پوشه را می‌خواند.

## API

### بازگشت

- Promise

| پارامتر | توضیح                         | نوع     | توضیح                    |
| ------- | ----------------------------- | ------- | ------------------------ |
| result  | آرایه‌ای از همه فایل‌های پوشه | `array` | آرایه‌ای از مسیرهای فایل |

### گزینه‌ها

| پارامتر | توضیح       | نوع      | پیش‌فرض |
| ------- | ----------- | -------- | ------- |
| options | { dirPath } | `object` | الزامی  |
| dirPath | مسیر پوشه   | `string` | الزامی  |
