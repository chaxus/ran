# WriteFile

محتوایی را در یک فایل می‌نویسد.

## API

### بازگشت

- Promise

| پارامتر | توضیح                                                | نوع       | توضیح                         |
| ------- | ---------------------------------------------------- | --------- | ----------------------------- |
| success | اینکه نوشتن موفق بوده یا نه                          | `boolean` | در موفقیت true، در شکست false |
| data    | دلیل شکست نوشتن، یا در صورت موفقیت محتوا و مسیر فایل | `any`     |                               |

### گزینه‌ها

| پارامتر | توضیح                            | نوع      | پیش‌فرض   |
| ------- | -------------------------------- | -------- | --------- |
| path    | مسیر فایلی که در آن نوشته می‌شود | `string` | undefined |
| content | محتوایی که نوشته می‌شود          | `string` | الزامی    |
