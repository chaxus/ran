# getCookie

مقدار کوکی با نام داده‌شده را می‌گیرد.

## API

### بازگشت

| آرگومان  | توضیح                      | نوع      |
| -------- | -------------------------- | -------- |
| `string` | مقدار کوکی با نام مشخص‌شده | `string` |

### گزینه‌ها

| آرگومان | توضیح                        | نوع      | پیش‌فرض |
| ------- | ---------------------------- | -------- | ------- |
| `name`  | نام کوکی‌ای که خوانده می‌شود | `string` | الزامی  |

## نمونه

```js
import { getCookie } from 'ranuts';

const result = getCookie('name');

console.log(result);

// ''
```
