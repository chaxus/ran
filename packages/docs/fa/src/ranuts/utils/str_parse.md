# strParse

با جداکننده و علامت تساویِ دلخواه، یک رشته را به شیء تجزیه می‌کند.

## API

### strParse

#### بازگشت

| آرگومان  | توضیح         | نوع                      |
| -------- | ------------- | ------------------------ |
| `Object` | شیء ساخته‌شده | `Record<string, string>` |

#### پارامترها

| پارامتر | توضیح                             | نوع                | پیش‌فرض |
| ------- | --------------------------------- | ------------------ | ------- |
| `str`   | رشته‌ای که تجزیه می‌شود           | `string`           | `''`    |
| `sep`   | جداکنندهٔ میان جفت‌های کلید-مقدار | `string \| RegExp` | `''`    |
| `eq`    | علامت تساوی میان کلید و مقدار     | `string \| RegExp` | `''`    |

## نمونه

### کاربرد پایه (رشتهٔ پرس‌وجوی نشانی)

```js
import { strParse } from 'ranuts';

const query = 'a=1&b=2&c=3';
const result = strParse(query, '&', '=');
console.log(result); // { a: '1', b: '2', c: '3' }
```

### جداکنندهٔ دلخواه

```js
import { strParse } from 'ranuts';

const str = 'name:John,age:30,city:NY';
const result = strParse(str, ',', ':');
console.log(result); // { name: 'John', age: '30', city: 'NY' }
```

### استفاده از عبارت باقاعده

```js
import { strParse } from 'ranuts';

const str = 'a=1|b=2|c=3';
const result = strParse(str, /\|/, '=');
console.log(result); // { a: '1', b: '2', c: '3' }
```

### مقدارهای خالی

```js
import { strParse } from 'ranuts';

const str = 'a=1&b=&c=3';
const result = strParse(str, '&', '=');
console.log(result); // { a: '1', c: '3' } (مقدارهای خالی کنار می‌روند)
```

## یادداشت‌ها

1. **جداکننده‌ها**: آرگومان نخست جفت‌های کلید-مقدار را جدا می‌کند (مانند `&`) و آرگومان دوم کلید را از مقدار (مانند `=`).
2. **کنار گذاشتن مقدار خالی**: اگر کلید یا مقدار خالی باشد، آن جفت کنار می‌رود و در شیء نتیجه نمی‌آید.
3. **پاک‌سازی خودکار**: کلیدها و مقدارها با `clearStr` پاک می‌شوند (فاصله، گیومه و مانند آن برداشته می‌شود).
4. **پشتیبانی از عبارت باقاعده**: جداکننده هم رشته می‌تواند باشد و هم عبارت باقاعده.
