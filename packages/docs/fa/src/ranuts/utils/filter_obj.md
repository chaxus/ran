# filterObj

ویژگی‌های یک شیء را می‌پالاید: هرچه کلیدش در آرایه `list` باشد برداشته می‌شود و شیئی تازه برمی‌گردد. بیشتر برای پاک کردن رشته‌های خالی و مقدارهای null به کار می‌رود.

## API

### بازگشت

| آرگومان  | توضیح           | نوع      |
| -------- | --------------- | -------- |
| `Object` | شیءِ پالوده‌شده | `Object` |

### گزینه‌ها

| آرگومان | توضیح                                | نوع      | پیش‌فرض |
| ------- | ------------------------------------ | -------- | ------- |
| `obj`   | شیئی که پالوده می‌شود                | `object` | الزامی  |
| `list`  | کلیدهایی که از `obj` برداشته می‌شوند | `array`  | الزامی  |

## نمونه

```js
import { filterObj } from 'ranuts';

const obj = {
  name: 'chaxus',
  age: 10,
  address: 'spark',
};

const result = filterObj(obj, ['name', 'address']);

console.log(result);

// { age:10 }
```
