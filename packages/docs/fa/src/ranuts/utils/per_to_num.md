# perToNum

رشتهٔ درصد را به عدد تبدیل می‌کند.

## API

### perToNum

#### بازگشت

| آرگومان  | توضیح         | نوع      |
| -------- | ------------- | -------- |
| `number` | عدد تبدیل‌شده | `number` |

#### پارامترها

| پارامتر | توضیح      | نوع      | پیش‌فرض |
| ------- | ---------- | -------- | ------- |
| `str`   | رشتهٔ درصد | `string` | `''`    |

## نمونه

### کاربرد پایه

```js
import { perToNum } from 'ranuts';

console.log(perToNum('50%')); // 0.5
console.log(perToNum('100%')); // 1
console.log(perToNum('150%')); // 1.5
```

### درصدهای بزرگ‌تر از ۱

```js
import { perToNum } from 'ranuts';

console.log(perToNum('50%')); // 0.5 (۱ یا کمتر است، همان‌طور برمی‌گردد)
console.log(perToNum('150%')); // 1.5 (از ۱ بیشتر است، بر ۱۰۰ تقسیم می‌شود)
console.log(perToNum('200%')); // 2
```

### رشته‌های عددی معمولی

```js
import { perToNum } from 'ranuts';

console.log(perToNum('0.5')); // 0.5
console.log(perToNum('100')); // 100
```

### رشته خالی

```js
import { perToNum } from 'ranuts';

console.log(perToNum('')); // 0
console.log(perToNum()); // 0
```

## یادداشت‌ها

۱. **رفتار با درصد**:

- اگر مقدار از ۱ بیشتر باشد، بر ۱۰۰ تقسیم می‌شود (مثلاً `150%` → `1.5`)
- اگر ۱ یا کمتر باشد، همان‌طور برمی‌گردد (مثلاً `50%` → `0.5`)

۲. **رشته‌های بدون درصد**: اگر رشته به `%` ختم نشود، مستقیم به عدد تبدیل می‌شود.

۳. **مقدار خالی**: رشتهٔ خالی `0` می‌دهد.

۴. **کاربرد**: معمولاً برای مقدارهای درصدی CSS و مقدارهای پیشرفت به کار می‌رود.
