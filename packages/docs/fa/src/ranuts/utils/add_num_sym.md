# addNumSym

به یک عدد نشانهٔ مثبت یا منفی (+ یا -) می‌افزاید.

## API

### addNumSym

#### بازگشت

| آرگومان  | توضیح                     | نوع      |
| -------- | ------------------------- | -------- |
| `string` | رشتهٔ عددی همراه با نشانه | `string` |

#### پارامترها

| پارامتر | توضیح                                       | نوع                | پیش‌فرض |
| ------- | ------------------------------------------- | ------------------ | ------- |
| `value` | عدد یا رشته‌ای که پردازش می‌شود             | `string \| number` | الزامی  |
| `flag`  | پرچم نشانه (اختیاری، برای اجبار کردن نشانه) | `string \| number` | اختیاری |

## نمونه

### کاربرد پایه

```js
import { addNumSym } from 'ranuts';

console.log(addNumSym(100)); // '+100'
console.log(addNumSym(-50)); // '-50'
console.log(addNumSym(0)); // '0'
```

### ورودی به شکل رشته

```js
import { addNumSym } from 'ranuts';

console.log(addNumSym('100')); // '+100'
console.log(addNumSym('-50')); // '-50' (از پیش نشانه دارد و دست‌نخورده می‌ماند)
```

### اجبار کردن نشانه

```js
import { addNumSym } from 'ranuts';

console.log(addNumSym(100, 1)); // '+100' (flag > 0)
console.log(addNumSym(100, -1)); // '100' (flag <= 0 است، پس + افزوده نمی‌شود)
console.log(addNumSym(100, 0)); // '100'
```

### وقتی نشانه از پیش هست

```js
import { addNumSym } from 'ranuts';

console.log(addNumSym('+100')); // '+100' (از پیش نشانه دارد و دست‌نخورده می‌ماند)
console.log(addNumSym('-50')); // '-50' (از پیش نشانه دارد و دست‌نخورده می‌ماند)
```

## یادداشت‌ها

1. **قاعدهٔ نشانه**:

- به عددهای مثبت `+` افزوده می‌شود
- عددهای منفی `-` خود را نگه می‌دارند
- صفر نشانه‌ای نمی‌گیرد

2. **نشانهٔ از پیش موجود**: اگر رشته با `+` یا `-` آغاز شود، نشانهٔ تازه‌ای افزوده نمی‌شود.

3. **پرچم اجبار**: با آرگومان `flag` می‌توانید تعیین کنید که `+` گذاشته شود یا نه (وقتی `flag > 0` باشد گذاشته می‌شود).

4. **کاربرد**: معمولاً برای نمایش سود و زیان، تغییرها و هر جا که مثبت و منفی باید روشن دیده شود به کار می‌رود.
