# md5

تابع درهم‌ساز MD5 که یک رشته را به مقدار درهم MD5 (رشتهٔ شانزده‌شانزدهی) تبدیل می‌کند.

## API

### md5

#### بازگشت

| آرگومان  | توضیح                                 | نوع      |
| -------- | ------------------------------------- | -------- |
| `string` | مقدار درهم MD5 (رشتهٔ شانزده‌شانزدهی) | `string` |

#### پارامترها

| پارامتر | توضیح                  | نوع      | پیش‌فرض |
| ------- | ---------------------- | -------- | ------- |
| `str`   | رشته‌ای که درهم می‌شود | `string` | الزامی  |

## نمونه

### کاربرد پایه

```js
import { md5 } from 'ranuts';

const hash = md5('hello world');
console.log(hash); // '5eb63bbbe01eeed093cb22bb8f5acdc3'
```

### درهم‌سازی گذرواژه

```js
import { md5 } from 'ranuts';

const password = 'myPassword123';
const hashedPassword = md5(password);
console.log(hashedPassword);
```

### درهم‌سازی محتوای فایل

```js
import { md5 } from 'ranuts';

const fileContent = 'محتوای فایل اینجا';
const fileHash = md5(fileContent);
console.log('درهم فایل:', fileHash);
```

### وقتی رشته داده نشود

```js
import { md5 } from 'ranuts';

// اگر چیزی جز رشته داده شود، یک رشتهٔ تصادفی برمی‌گردد
const result = md5(123);
console.log(result); // رشتهٔ تصادفی
```

## یادداشت‌ها

۱. **امنیت**: MD5 ناامن شمرده می‌شود و نباید برای نگهداری گذرواژه یا هر کار حساسی به کار رود. الگوریتم استوارتری مانند SHA-256 را توصیه می‌کنیم.
۲. **نوع ورودی**: اگر ورودی رشته نباشد، تابع یک رشتهٔ تصادفی برمی‌گرداند.
۳. **قالب خروجی**: رشتهٔ شانزده‌شانزدهیِ ۳۲ نویسه‌ای با حروف کوچک.
۴. **کارایی**: با داده‌های حجیم محاسبه ممکن است کند شود، پس بهتر است در بستری ناهمگام انجام گیرد.
