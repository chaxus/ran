# isWeiXin

تعیین می‌کند که محیط کنونی مرورگر WeChat است یا نه.

## API

### isWeiXin

#### بازگشت

| آرگومان   | توضیح                         | نوع       |
| --------- | ----------------------------- | --------- |
| `boolean` | اینکه مرورگر WeChat است یا نه | `boolean` |

#### پارامترها

بدون پارامتر

## نمونه

### کاربرد پایه

```js
import { isWeiXin } from 'ranuts';

if (isWeiXin()) {
  console.log('اکنون در مرورگر WeChat هستیم');
} else {
  console.log('در مرورگر WeChat نیستیم');
}
```

### قابلیت‌های ویژه WeChat

```js
import { isWeiXin } from 'ranuts';

if (isWeiXin()) {
  // از JS-SDK وی‌چت استفاده کن
  wx.config({
    // پیکربندی
  });
} else {
  // از هم‌رسانی معمول استفاده کن
  shareToSocial();
}
```

### نمایش شرطی

```js
import { isWeiXin } from 'ranuts';

if (isWeiXin()) {
  // راهنمای ویژه وی‌چت را نشان بده
  showWeChatTip();
}
```

## یادداشت‌ها

1. **شیوه تشخیص**: بررسی می‌کند که رشته `micromessenger` در User Agent هست یا نه.

2. **رندر سمت سرور**: در محیط سرور (بدون شیء `window`) مقدار `false` برمی‌گرداند.

3. **دقت**: بر پایه User Agent است، پس اگر UA دستکاری شده باشد ممکن است درست تشخیص ندهد.

4. **نسخه‌های وی‌چت**: با همه نسخه‌های مرورگر وی‌چت کار می‌کند (از جمله مرورگر درون‌ساخت و WebView مینی‌برنامه‌ها).
