# Ran Design

یک چک‌لیست طراحی یک‌صفحه‌ای برای ساخت رابط محصول، مستقل از هر کتابخانهٔ کامپوننت.

پیش از شروع، هنگام ساخت و پیش از تحویل یک تغییر از آن استفاده کنید. آزمون پنج‌ثانیه‌ای و آزمون صندوق عقب استیو کراگ را در بر دارد و مواردی را که یک آزمون مرورگر خودکار بررسی می‌کند مشخص کرده است.
