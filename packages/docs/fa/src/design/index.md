# Ran Design

روش‌های چیدمان، تعامل، حرکت و ارزیابی با شواهد، مستقل از کتابخانهٔ مؤلفه‌ها.

از کار و محتوای واقعی شروع کنید. زبان بصری مشترکی برای محصول تعیین کنید و حالت‌های کامل، از جمله صفحه‌کلید و حرکت، را در مرورگر بررسی کنید. قراردادهای دقیق در منابع زیر آمده‌اند.
