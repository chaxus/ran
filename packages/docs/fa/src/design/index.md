# Ran Design

راهنمای طراحی برای ساخت رابط محصول، مستقل از هر کتابخانهٔ کامپوننت.

به همان ترتیبی پیش می‌رود که طراحی می‌کنید: از کار و محتوای واقعی شروع کنید، یک زبان بصری واحد انتخاب کنید، صفحه را بچینید و ترکیب کنید، تعامل و حرکت را طراحی کنید و در پایان تغییر را در یک مرورگر واقعی بررسی کنید. در انتها چک‌لیست‌هایی برای هر تغییر آمده است.
