# Ran Design

A one-page design checklist for people and coding agents building the interface of a web product, in
any stack: [DESIGN.md](./DESIGN.md).

This is the editable source. The ranui npm guide composes it with ranui's
[implementation adapter](https://github.com/chaxus/ran/blob/main/packages/ranui/docs/adapters/DESIGN.md),
and the agent plugin distributes a checked copy. Edit this source, then run `pnpm sync:design` and
`pnpm sync:agent-plugin` from the ran repository. Consuming the checklist requires no checkout.
