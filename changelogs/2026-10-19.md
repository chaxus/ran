The npm registry records all three publications on 2026-10-19 (Asia/Shanghai). The `latest` tags, published package metadata and downloaded archive SHA-512 values were verified on that date. Packed dependencies use the exact coordinated versions: ranview depends on ranuts 0.5.0, and ranui depends on ranuts 0.5.0 and ranview 0.2.0.

- Repository and package READMEs now use the published versions in installation and CDN examples. Both source changelogs and all eight generated changelog pages reflect the publication.
