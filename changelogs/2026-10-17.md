# Changelog — 2026-10-17

## ranui

- Treat input and select labels as plain text on every update.
- Synchronize dynamic input type, disabled, value and numeric constraints with the native control. Attribute changes now update form submission values, including value removal.
- Relay native input validity (including email and number constraints) to the associated form and accessibility state.
- Read raw SVG imports as text instead of exporting a file-result wrapper.

## ranuts

- Isolate HTTP middleware state per request while preserving application context defaults.
- Resolve declaration aliases and relative imports for Bundler and NodeNext consumers. File result types no longer depend on a repository-only ambient namespace; build declarations exclude tests.
- Mark ESM modules as free of import side effects, preserving UMD initialization. A packed-package check verifies consumer types, ESM/CommonJS imports and a 1 KiB gzip budget for a single color helper import.

## Checks

- Run the packed-package consumer check in CI after builds.
- Trigger integration browser tests for changes to ranui, ranuts, ranview, im and shared dependency configuration.
